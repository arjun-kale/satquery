## Team LoRA Checkpoint (M2 — BigEarthNet.txt on GeoChat-7B)

### Base model

**Base model used:** `MBZUAI/geochat-7B` @ `cca91eb` (Apache-2.0) — no substitution.

GeoChat is published in the original LLaVA training layout (`GeoChatLlamaForCausalLM`, `model_type: geochat`), so `LlavaForConditionalGeneration.from_pretrained` fails with *"The checkpoint you are trying to load has model type `geochat` but Transformers does not recognize this architecture"*. `convert_geochat` rewrites it once into the llava-hf layout, rebuilding GeoChat's vision tower exactly as its loader does (CLIP ViT-L/14-336, position embeddings bicubic-interpolated to 504 px → 1,296 image tokens).

**Conversion check vs. the original GeoChat code** (github.com/mbzuai-oryx/GeoChat@4850920e005a849bd224d0ce35aa9db031fa5155 with transformers 4.31.0, fp16), on 3 prompts — **PASSED** ([verification.json](evidence/m2/geochat_conversion/verification.json)):

| Prompt | identical input ids | pixel max abs diff | next-token argmax identical | logits cosine | greedy text identical |
|---|---|---|---|---|---|
| `Is there any coniferous forest in this image?` | True | 8.9e-04 | True | 1.00000 | True |
| `[refer] Where can the <p>pastures</p> be found?` | True | 8.9e-04 | True | 0.99997 | True |
| `Describe this satellite image.` | True | 8.9e-04 | True | 0.99999 | True |

One-off conversion + verification cost (all attempts, incl. 3 that stopped early on strict weight checks): $0.17 (actual).

### Architecture decision

A **fresh** `LoraConfig` (r=32, α=64, dropout 0.05) on GeoChat's language-model attention and MLP projections (`q/k/v/o_proj`, `gate/up/down_proj`), vision tower and projector frozen. We did **not** continue the M1 EuroSAT adapter: it was trained on generic LLaVA-1.5 weights, so it does not apply to GeoChat's weights, and GeoChat is already remote-sensing adapted by its authors. QLoRA: 4-bit NF4 base with double quantization, bf16 compute and bf16 training (not fp16).

Prompts follow GeoChat's own conventions (`llava_v1` template; `[refer] … <p>phrase</p>` for grounding; boxes as `{<x1><y1><x2><y2>|<90>}` on a 0–100 grid, converted from BigEarthNet.txt's `[x1 y1, x2 y2]`, whose x-first order was checked on 1,610 relative-position questions). The base model is evaluated with the same prompts, so the baseline measures GeoChat's real ability rather than its unfamiliarity with a new syntax. Images are Sentinel-2 B04/B03/B02 rendered with the same 2–98% per-band stretch the backend uses for previews (`backend/app/ingestion/preview.py`; a unit test fails if the two drift apart).

## Serving (MVP)

**Deployed:** `modal_worker/infer.py` → Modal app `satquery-m1-infer`, class `GeoChatInfer` (name kept so the backend lookup is unchanged). It serves converted GeoChat-7B (4-bit) + the **scaled** M2 adapter and reports which weights answered (`weights` field, incl. adapter sha256). `min_containers=0`: no always-on GPU; first call after 5 idle minutes pays a cold start.

**End-to-end check** through the backend's own `GeoChatAdapter(mode="modal")` on 3 held-out test patches ([smoke_test_report.json](evidence/m2/scaled/samples/smoke_test_report.json), inputs in the same folder): captions in BigEarthNet style naming the right land-cover classes; VQA answer correct; `ground()` returns the box the model generated (previously a hard-coded placeholder). First call 47 s incl. cold start, then 13–22 s.

**Limits to state in the demo:**
- **Domain:** trained and evaluated on Sentinel-2 RGB, 10 m, Lithuania, summer. Other regions, seasons, SAR or high-resolution imagery are out of distribution.
- **Referring-expression grounding** ("where is the pasture?") is not learned — it usually returns the whole image (see table). Point-prompted grounding works (0.84 Acc@0.5).
- **Areas quoted in captions** (e.g. "~1,000,000 sqm") imitate the training captions' style; they are not measurements. Use the deterministic geodesy/spectral tools for any number shown as a measurement.
- **Confidence** is the geometric-mean token probability — model-derived, not calibrated (a whole-image box came back at 0.81).
